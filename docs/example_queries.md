## Dossier AUTO-2026-0087
Analyse complète du dossier automobile.
1. Lister les pièces reçues et manquantes.
2. Extraire la date, l'heure, le lieu et les véhicules.
3. Comparer les récits des deux conducteurs.
4. Identifier les informations conflictuelles.
5. Comparer les devis de réparation.
6. Identifier les garanties disponibles.
7. Expliquer les documents complémentaires requis.
Pour chaque constat, indiquer le fichier source et le numéro de page exact.
